                  ├──────────────────────┤
                  │ date (PK)            │
                  │ year, quarter, month │
                  └──────────┬───────────┘
                             │ 1
                             │
                             │ *
┌──────────────────────┐   ┌─┴────────────────────┐   ┌──────────────────────┐
│     dim_customer     │   │      fact_sales      │   │     dim_product      │
├──────────────────────┤   ├──────────────────────┤   ├──────────────────────┤
│ customer_id (PK)     ├───┤ customer_id (FK)     ├───┤ product_id (PK)      │
│ customer_name        │ 1*│ order_id             │* 1│ product_name         │
│ gender, age, city    │   │ order_date (FK)      │   │ category, subcat     │
│ customer_segment     │   │ product_id (FK)      │   │ brand, unit_cost/prc │
└──────────┬───────────┘   │ region_id (FK)       │   └──────────────────────┘
           │               │ quantity, discount   │
           │               │ sales_amount, profit │
           │               └─┬────────────────────┘
           │                 │ *

## 🛠️ Technology Stack & Analytical Implementation

- **Database Engine:** PostgreSQL 14+ with primary/foreign keys, B-tree indexes, check constraints, and 27 analytical queries utilizing `LAG()`, `DENSE_RANK()`, `NTILE()`, and Common Table Expressions (CTEs).
- **Data Engineering & Analytics:** Python 3.13, Pandas 2.0+, NumPy with automated 10-stage data pipeline (`01_data_validation.py` to `06_rfm_segmentation.py`).
- **Spreadsheet Modeling:** Microsoft Excel (`retail_sales_analysis.xlsx` & `retail_raw_and_cleaned_master.xlsx`) with dynamic formulas (`SUMIFS`, `COUNTIFS`, `AVERAGEIFS`, `XLOOKUP`), Pivot Tables, and 5-Year Trajectory.
- **Business Intelligence & DAX:** Power BI Desktop star schema data modeling with 15+ custom production DAX measures for time intelligence and margin calculations.
- **Web Application & UI:** Interactive single-page dashboard deployed on GitHub Pages with Chart.js and Tailwind CSS, plus local Streamlit application (`app.py`).
